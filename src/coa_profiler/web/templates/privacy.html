Privacy notice

What is processed

The file you upload and the chemistry values extracted from it. The server creates an owner-only temporary working directory for the upload.

What is never retained

  • Your original uploaded file — removed as soon as the metadata-scrubbed working copy is created.
  • The scrubbed working copy — held in an owner-only temporary directory and deleted when your session ends.
  • The parsed values and your result — kept only in memory, never written to a database.
  • IP-derived identities — see the access-log section below.
  • Accounts — there is no account, no registration, and no login on this service.

No account, no durable storage of results, and no third-party tracking. Parsed values remain only in the server process for the short session; temporary working data is discarded when that session ends.

External processing

{% if inference_assist_enabled %}

External inference is enabled for this deployment. When the deterministic parser cannot recognize a report layout, extracted document text may be sent to the operator-configured inference service to classify that layout. The service does not extract chemistry values. Upload only documents you are authorized to send to that service.

{% else %}

External inference is disabled for this deployment. Files, extracted document text, and chemistry values are not sent to an inference service.

{% endif %}

The session

Your result lives in a session that expires {{ ttl_minutes }} minutes after your upload. When it ends, the session is torn down automatically and the working copy of your file is deleted.

The only cookie is the functional session cookie: HttpOnly, SameSite=Strict{% if cookie_secure %}, Secure{% endif %}. No other cookies are set. The page never reads the cookie, and no result data appears in URLs.

Photo metadata

Image metadata (EXIF), including any location or device data, is stripped from photos on upload before anything else happens. HEIC photos are handled the same way through the HEIC decoder; when the decoder is unavailable, HEIC uploads are refused before processing rather than processed without stripping.

Access logs

Within the {{ ttl_minutes }}-minute session window, someone with access to server logs could correlate your IP address with a visit to the results page. By default, IP addresses in access logs are hashed using a daily rotating salt, reducing but not eliminating this correlation risk. Operators may configure logging to truncate or fully disable IP retention via the LOG_IP_RETENTION setting (current deployment: {{ log_ip_retention }}).

Anonymous feedback

If you choose to answer “Was this helpful?”, the only data recorded is derived and non-identifying: the placement number, the completeness state, and the lab report format. No IP address, no session token, and no chemistry values are attached.
